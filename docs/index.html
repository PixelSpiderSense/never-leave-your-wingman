Never Leave Your Wingman

A second brain for AI coding agents that doesn't trust what it reads. One rule file, shared skills and plain-markdown memory for Claude Code, Codex, Cursor and Gemini CLI.

View on GitHub Quick start

Why use it

  • One rule file for every AI tool. AGENTS.md is the single source of truth; CLAUDE.md and GEMINI.md import it.
  • Memory that survives the session. Decisions, lessons and research live in a git-versioned markdown vault.
  • Safer by default. Untrusted-input policy, a scanner for third-party material, a staged-secret check and confirm-before-saving rules.
  • Agents that hand work to each other. Five roles pass tasks through inbox and outbox notes.
  • Eleven skills included, as plain SKILL.md files, under the MIT licence.

FAQ

What is a second brain for AI agents?

A folder of plain markdown notes (decisions, lessons, research, handoffs) plus written rules, kept in git, that every AI coding agent reads at the start of a session. The agent gets persistent memory and consistent behaviour without any database or hosted service.

What is AGENTS.md, and how is it different from CLAUDE.md?

AGENTS.md is an open convention for telling coding agents how to work in a project. Codex and Cursor read it directly. Claude Code reads CLAUDE.md, so this repo makes CLAUDE.md a single line, @AGENTS.md, that imports it. Gemini CLI works the same way with GEMINI.md.

How do I use one set of rules in Claude Code, Cursor and Codex?

Keep the rules in AGENTS.md, add a CLAUDE.md that imports it, and optionally install GLOBAL-AGENTS.md into each tool's user-level file.

How do I protect an AI agent from prompt injection in repos I clone?

Treat file contents as data, not instructions. This repo states that rule in AGENTS.md and ships scripts/scan_untrusted.py, which screens third-party material for hidden instructions, invisible characters and risky config before it is read in bulk. It is a screen, not a guarantee.

Do I need Obsidian?

No. It is plain markdown with YAML frontmatter and wikilinks, so Obsidian works but any editor does.

Is it free, and does it send my data anywhere?

It is MIT licensed and free. Everything is local files in your git repository. The optional Slack and Notion mirrors are off until you add your own credentials.
